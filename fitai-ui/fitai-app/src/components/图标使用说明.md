# 图标使用说明

## 1. Iconify 图标（联网加载）

图标从 https://api.iconify.design 按需加载，无需打包。

```vue
<IconifyIcon icon="mdi:home" :size="24" color="#3b82f6" />
<IconifyIcon icon="ep:shop" :size="24" />
```

**常用图标集：**
- `mdi:` - Material Design Icons
- `ep:` - Element Plus 风格
- `carbon:` - IBM Carbon
- 更多: https://icon-sets.iconify.design/

## 2. Element Plus 图标

```vue
<ElIcon name="House" :size="24" />
<ElIcon name="Shop" :size="24" />
<ElIcon name="ShoppingCart" :size="24" />
<ElIcon name="User" :size="24" />
<ElIcon name="ChatDotRound" :size="24" />
```

**常用图标名：** House, Shop, ShoppingCart, User, UserFilled, ChatDotRound, Reading 等  
完整列表: https://element-plus.org/zh-CN/component/icon.html

## 3. iconfont 阿里巴巴矢量图标

1. 访问 https://www.iconfont.cn/
2. 创建项目，添加所需图标
3. 获取 Symbol 或 FontClass 的 CDN 链接
4. 在 `index.html` 或 `App.vue` 中引入：
   ```html
   <script src="//at.alicdn.com/t/xxx.js"></script>
   ```
5. 使用：`<text class="iconfont icon-xxx"></text>`

**注意：** uni-app 原生 tabBar 的 `iconPath` 仅支持本地 PNG 路径，不支持 iconfont。如需在 tabBar 使用更好看的图标，可从 iconfont 下载 PNG 后放入 `static/tabbar/`。
